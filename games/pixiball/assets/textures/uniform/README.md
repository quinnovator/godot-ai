# Generated uniform textures

2026-07-12 for this project. It is a neutral, seamless baseball double-knit
albedo detail tile with no logos, text, garment seams, or player likenesses.
`BallplayerActor` samples it triplanar and multiplies only a restrained tonal
variation into runtime team colors; normal and roughness response still comes
from the separately documented CC0 surface maps.
