# Graduate uniform font

`Graduate-Regular.ttf` is the Graduate typeface distributed by the official
Google Fonts repository. It is rendered into high-resolution roster textures
for the Blender-authored front/back jersey UV panels: team marks, player
surnames, and jersey numbers. The complete SIL Open Font License 1.1 is included
in `OFL.txt`.

Source: <https://github.com/google/fonts/tree/main/ofl/graduate>
