# Unreal UI font set

These files are unchanged copies of the authoritative Pixiball Unreal project
font set under `Content/Fonts/`:

- `PixelifySans-Regular.ttf`: display labels and titles
- `DotGothic16-Regular.ttf`: body copy and fallback glyphs
- `VT323-Regular.ttf`: scores and numeric readouts

All three font families are distributed under the SIL Open Font License 1.1.
The license text is included as `OFL.txt`.
